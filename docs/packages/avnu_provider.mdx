## Introduction

This package talks to Avnu's paymaster over **SNIP-29 JSON-RPC**. The paymaster returns **SNIP-9 outside execution** typed data for the user to sign; Avnu's relayer then submits the transaction and covers or tokenizes gas according to the selected fee mode.

Configure:

- `AVNU_RPC` — e.g. `https://sepolia.paymaster.avnu.fi`
- `AVNU_API_KEY` — from [portal.avnu.fi](https://portal.avnu.fi)

## API

`AvnuPaymasterProvider` exposes:

| Method | SNIP-29 RPC |
| --- | --- |
| `isAvailable()` | `paymaster_isAvailable` |
| `getSupportedTokens()` | `paymaster_getSupportedTokens` |
| `buildTransaction(transaction, parameters)` | `paymaster_buildTransaction` |
| `executeTransaction(transaction, parameters)` | `paymaster_executeTransaction` |
| `trackingIdToLatestHash(trackingId)` | `paymaster_trackingIdToLatestHash` |
| `setApiKey(apiKey)` | sent as `x-paymaster-api-key` header |

Key models:

- `UserTransaction` — `deploy`, `invoke`, or `deploy_and_invoke`
- `UserParameters` — `version: 0x1`, `FeeMode.sponsored()` or `FeeMode.defaultMode(gasToken: ...)`
- `PaymasterBuildResponse` — typed data + fee estimate
- `OutsideExecutionTypedData` — use `.hash(accountAddress)` before signing

Use `PaymasterCall.fromEntrypoint` so selectors are canonical felt hex strings.

Errors throw `PaymasterRpcException` with `PaymasterErrorCode` when recognized.

## Flow

1. `buildTransaction` with calls and fee mode.
2. Sign `build.typedData` (invoke / deploy_and_invoke).
3. `executeTransaction` with the same `parameters` returned from build.
4. Optionally poll `trackingIdToLatestHash` using the `tracking_id` from execute.

Deploy-only accounts skip typed data: build and execute with `UserTransaction.deploy`.

## Examples

- `example/avnu_argent_transfer_eth.dart` — sponsored ETH transfer
